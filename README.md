# אטלס העולמות

מערכת מפות אינטראקטיביות לעולמות דמיוניים: מעלים תמונת מפה, מוסיפים עליה מקומות (סיכות) עם שם, סוג ותיאור, ומקשרים בין מפות (למשל מפת ממלכה ← מפת עיר).

## איך מפעילים
פותחים את `index.html` בדפדפן. אין צורך בהתקנה.

## יכולות
- כמה מפות, כל אחת מתמונה (PNG/JPG) שמעלים
- הוספת מקום בלחיצה על המפה, עריכה, מחיקה וגרירה להזזה
- 8 סוגי מקומות עם צבע ואייקון, וסינון לפי שכבות
- חיפוש מקומות ורשימה בצד
- קישור ממקום למפה אחרת, עם "פירורי לחם" לחזרה
- שמירה אוטומטית בדפדפן (IndexedDB) + ייצוא/ייבוא גיבוי JSON
- מותאם לטלפון

נבנה עם [Leaflet](https://leafletjs.com).
